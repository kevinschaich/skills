# kevinschaich-skills

My Claude Code skills, packaged as a plugin marketplace.

| Skill | What it does |
| --- | --- |
| `fmk` | Fuck-marry-kill: find the right answer to anything by elimination, round by round. |
| `reverse-engineer-anything` | Reverse engineer binaries, Electron/JS apps, firmware and web targets with the REA MCP server. |

## Install

In Claude Code:

```
/plugin marketplace add kevinschaich/skills
/plugin install kevinschaich-skills@kevinschaich-skills
```

`reverse-engineer-anything` expects the REA MCP server to be available.
